Quick Start Guide for VX API with Cherry Studio · 零代码，5 分钟上线
VX API is an OpenAI-compatible API gateway. Cherry Studio is a desktop AI chat client. Together they let you chat with DeepSeek, Qwen, GLM, Kimi and more using one key.
VX API 是一个 OpenAI 兼容的 API 网关。Cherry Studio 是一个桌面 AI 聊天客户端。两者结合，你只需一把 Key 就能使用 DeepSeek、Qwen、GLM、Kimi 等模型。

Step 1 · 注册账号并创建 API Key / Sign up & create an API key

1
访问 VX API 控制台
Open https://api.vxvxvx.top and sign up / log in.
2
进入「API 密钥」页面
Go to API Keys / API 密钥 in the left sidebar.
3
新建 Key
Click Add Token / 添加令牌. Fill: Name=cherry-test, Group=default, Quota=10 (turn off "Unlimited" if it causes issues). Copy the key starting with sk- and save it.
提示 / Tip: If the key status shows "Disabled", click the green power icon to enable it before testing.
如果 Key 状态显示"已禁用"，请先点绿色电源图标启用后再测试。

Step 2 · 安装 Cherry Studio / Install Cherry Studio

1
下载
Go to https://cherry-ai.com and download the Windows installer. Run it and open the app.
2
首次启动
Select 简体中文 as the language. When the welcome screen appears, choose "配置其他服务商" / "Configure other providers" (do NOT click "Connect CherryIN").

Step 3 · 添加 VX API 作为服务商 / Add VX API as an OpenAI-compatible provider

1
进入模型服务设置
Click the ⚙️ gear icon at bottom-left → 模型服务 / Model Services → + 添加 / Add.
2
选择 OpenAI 类型
Choose OpenAI (OpenAI-compatible).
3
填入三个字段
名称 / NameVX API
API 地址 / API URLhttps://api.vxvxvx.top/v1
API 密钥 / API Keysk-xxxxxxxxxxxxxxxx (paste your saved key)
注意 / Note: The URL must end with /v1. Missing it will cause a 404 error.
地址末尾必须有 /v1，漏掉会报 404 错误。
4
保存并检查
Click 添加 / Add, then click 检查 / Check. You should see a ✓ success message.

Step 4 · 同步并选择模型 / Sync and select a model

1
同步模型
In the VX API provider card, click 同步模型 / Sync Models. Wait for the list to load (about 29 models).
2
选择模型
Find and check DeepSeek V4.1 Flash (model id: deepseek-v4-flash-2k). Click 下一步 / Next.
3
设为默认
On the "Default Model" screen, select DeepSeek V4.1 Flash as your default assistant model, then click 开始使用 / Start.

Step 5 · 开始聊天 / Start chatting

In the main chat window, make sure the top model shows DeepSeek: DeepSeek V4.1 Flash. Type a message and press Enter.
回到主界面，确认顶部模型显示 DeepSeek: DeepSeek V4.1 Flash，输入消息并按回车。
成功示例：发送"1+1等于几？"后 AI 回复"1+1等于2。" / Success example: "1+1=2" response.
省钱提示 / Budget tip: DeepSeek V4.1 Flash is cheap and stable. Avoid the "超低价/不过检 / ultra-low cost / no-filter" group for demos.
DeepSeek V4.1 Flash 便宜又稳定。演示时避免使用"超低价/不过检"分组里的模型。

🛠️ 常见报错 / Troubleshooting

403 用户额度不足，剩余额度：¥0.000000

原因 / Cause: Your API key is disabled or its quota state is stuck at zero even though the dashboard shows a positive balance.
API 密钥被禁用，或额度状态异常（即使账号余额显示正常）。

解决 / Fix:
1. Go to API 密钥 / API Keys, find your key, and click the green power icon to enable it if it shows "Disabled / 已禁用".
2. If enabling does not help, create a new key with a fixed quota (e.g., 10) and replace the old key in Cherry Studio.
1. 到「API 密钥」找到这把 Key，如果显示"已禁用"，点绿色电源图标启用。
2. 如果启用后仍报错，新建一把固定额度（例如 10）的 Key，并在 Cherry Studio 里替换旧 Key。
401 Failed to authenticate

原因 / Cause: API key is wrong, incomplete, or has spaces.
API 密钥错误、不完整或包含空格。

解决 / Fix: Re-copy the full key from the dashboard (starts with sk-, usually 40+ characters). Paste it without leading/trailing spaces.
重新从后台复制完整 Key（sk- 开头，通常 40 字符以上），粘贴时确保没有前后空格。
404 Not Found

原因 / Cause: The API URL is missing /v1.
API 地址缺少 /v1。

解决 / Fix: Use exactly https://api.vxvxvx.top/v1.
必须完整填写 https://api.vxvxvx.top/v1。

🚀 下一步 / What's next

Once connected, you can switch between models in Cherry Studio and use the same API key for other OpenAI-compatible tools like Chatbox, Open WebUI, or your own code.
接入成功后，你可以在 Cherry Studio 里切换模型，也可以把同一把 Key 用到 Chatbox、Open WebUI 或其他 OpenAI 兼容工具里。
